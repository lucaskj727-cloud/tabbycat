# 🚀 Deploy DebateFlow Now - Quick Cloud Deployment

**Want to use DebateFlow right now?** This guide will have you up and running in 10 minutes with a free cloud deployment.

## ⚡ Fastest Option: Deploy to Render (Free)

Render offers a free tier perfect for trying out DebateFlow.

### Step 1: Fork the Repository

1. Visit https://github.com/lucaskj727-cloud/tabbycat
2. Click **"Fork"** (top right)
3. This creates your own copy

### Step 2: Sign Up for Render

1. Go to https://render.com
2. Click **"Get Started for Free"**
3. Sign up with GitHub (recommended)

### Step 3: Deploy with One Click

1. Click the button below (or follow manual steps):

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

2. Or manually:
   - In Render dashboard, click **"New +"**
   - Select **"Web Service"**
   - Connect your GitHub account
   - Select your forked `tabbycat` repository
   - Render will detect the configuration automatically

### Step 4: Configure Environment

Render will ask for these settings:

- **Name**: `debateflow` (or your choice)
- **Branch**: `copilot/create-tabbycat-replica` (or `main`)
- **Build Command**: `npm install && npm run build && python manage.py collectstatic --noinput && python manage.py migrate`
- **Start Command**: `daphne tabbycat.asgi:application --port $PORT --bind 0.0.0.0`

Environment Variables (Render will prompt):
```
DATABASE_URL=(auto-generated by Render PostgreSQL)
DJANGO_SECRET_KEY=(generate a random string)
DEBUG=False
ON_RENDER=1
DISABLE_SENTRY=True
```

### Step 5: Add Database

1. In your Render service, go to **"Environment"**
2. Click **"+ Add Database"**
3. Select **"PostgreSQL"** (free tier available)
4. Render automatically sets `DATABASE_URL`

### Step 6: Create Admin User

After deployment completes:

1. Go to your service's **"Shell"** tab
2. Run:
   ```bash
   python manage.py createsuperuser
   ```
3. Follow prompts to create username/password

### Step 7: Access Your Site!

Your DebateFlow instance is live at:
```
https://your-service-name.onrender.com
```

## 🔵 Alternative: Deploy to Heroku

Heroku is battle-tested but requires a paid plan for most features.

### Quick Deploy

1. Click the Heroku button:
   [![Deploy](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy)

2. Or manually:
   ```bash
   # Install Heroku CLI
   # https://devcenter.heroku.com/articles/heroku-cli
   
   heroku login
   heroku create your-debateflow-name
   heroku addons:create heroku-postgresql:essential-0
   git push heroku copilot/create-tabbycat-replica:main
   heroku run python manage.py createsuperuser
   heroku open
   ```

### Environment Variables for Heroku

```bash
heroku config:set DEBUG=False
heroku config:set DJANGO_SECRET_KEY="$(openssl rand -base64 32)"
heroku config:set ON_HEROKU=1
heroku config:set DISABLE_SENTRY=True
```

## 💻 Local Development (If You Must)

If you prefer to run locally despite the complexity:

### Prerequisites
- Python 3.11+
- PostgreSQL 14+
- Node.js 16+
- Redis (optional, for caching)

### Quick Start

```bash
# 1. Clone
git clone https://github.com/lucaskj727-cloud/tabbycat
cd tabbycat

# 2. Database
sudo -u postgres psql -c "CREATE DATABASE debateflow;"
sudo -u postgres psql -c "CREATE USER debateflow WITH PASSWORD 'debateflow';"
sudo -u postgres psql -c "GRANT ALL ON DATABASE debateflow TO debateflow;"
sudo -u postgres psql -d debateflow -c "GRANT ALL ON SCHEMA public TO debateflow;"

# 3. Python setup
pip install pipenv
pipenv install
pipenv shell

# 4. Frontend
npm install
npm run build

# 5. Django setup
cp tabbycat/settings/local.example tabbycat/settings/local.py
# Edit local.py with your database credentials

python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Visit `http://localhost:8000`

## 🔧 Troubleshooting

### Build Fails

**Problem**: npm or pip install errors
**Solution**: 
```bash
# Clear caches
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Database Connection Errors

**Problem**: Can't connect to PostgreSQL
**Solution**:
- Verify `DATABASE_URL` is set correctly
- Check database addon is provisioned
- Run `python manage.py dbshell` to test connection

### Static Files Not Loading

**Problem**: CSS/JS missing
**Solution**:
```bash
npm run build
python manage.py collectstatic --noinput
```

### Can't Create Superuser

**Problem**: No terminal access
**Solution**:
- Use Render/Heroku web shell
- Or temporarily set environment variable to auto-create:
  ```python
  # In settings
  if os.environ.get('CREATE_SUPERUSER'):
      from django.contrib.auth import get_user_model
      User = get_user_model()
      if not User.objects.filter(username='admin').exists():
          User.objects.create_superuser('admin', 'admin@example.com', 'changeme123')
  ```
